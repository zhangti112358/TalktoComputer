# 人机交互可以更加自然且高效

人使用计算机的历史是：

1. 二进制数据
2. 命令行
3. 图形界面

随着计算机对信息处理能力的提升，人机交互的趋势有：

1. 交互方式更自然。
2. 交互的信息种类增加，效率更高。

现在LLM进一步提升了对信息的理解能力，因此可以把交互做得更好。
